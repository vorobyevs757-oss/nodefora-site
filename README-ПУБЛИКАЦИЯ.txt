NODEFORA — готовый статический сайт (версия пакета 2026-11-01)

КАК ПУБЛИКОВАТЬ НА ОБЫЧНОМ ХОСТИНГЕ
1. Распаковать ZIP.
2. Загрузить ВЕСЬ набор файлов и папок из ZIP в корень сайта: index.html, favicon.svg, assets/.
3. Открыть свой домен в браузере. Никаких npm, Node.js и Supabase на хостинге не нужно.

ВАЖНО
- Не загружать ZIP как один файл, если панель управления хостингом не распаковывает его автоматически.
- Если сайт открывается в подпапке, относительные пути сохраняются.
- Главная иллюстрация в assets/images/lab-hero.webp уже содержит правильный бренд NODEFORA.
- TestLab Web 2.0.2 (21.10.2026) и Mobile 1.5.0 показаны отдельными релизами.
- Содержимое патч-нотов сейчас размещено статически в assets/data.js.
- Автоматического доступа NODEFORA к закрытым данным Supabase TestLab пока НЕТ.
- Для автоматического обновления версий нужен отдельный проверенный публичный экспорт или защищённая интеграция.
- Четыре продукта, Roadmap, фильтры, поиск, страница об основателе работают без БД.

ДЛЯ GITHUB PAGES
Рекомендуем использовать отдельный архив NODEFORA-SOURCE-REACT.zip с GitHub Actions для автоматической сборки.
Если загружаете только статический ZIP на GitHub Pages, нужно настроить публикацию из корня ветки или из /docs.
